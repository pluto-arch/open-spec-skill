# Open Spec Reference

本目录提供 Open Spec 各阶段的详细执行参考，补充 `agents/` 中各 Agent 文件的方法论细节。

## 阶段参考文档

| 文件 | 对应阶段 |
|------|----------|
| `01-requirements-analysis-reference.md` | 需求分析 |
| `02-specification-authoring-reference.md` | 规范制定 |
| `03-solution-design-reference.md` | 方案设计 |
| `04-planning-and-implementation-reference.md` | 开发计划与实施 |
| `07-handoff-contract-example.md` | Handoff 契约示例 |

## 使用原则

- 阶段开始前阅读对应参考文档。
- 阶段产出后按文档中的自检清单执行一次自检。
- Handoff 摘要仅保留结论与增量，不复制完整推理过程。
